# Проектирование системы управления автоматом по приготовлению напитков

Курсовой проект по предмету ООП(программирование) 3 семестр

# Автор

Стороженко Д.К., группа ПИ-52

## Описание

Консольная модель автомата по приготовлению напитков. Позволяет заказывать кофейные, чайные и холодные напитки, проверяет наличие ингредиентов, списывает их при приготовлении, запрещает пополнение во время работы и ведёт учёт запасов.

## Сборка

g++ main.cpp *.cpp -o app
./app
